# Contributing to Next.js Shop Demo (OneEntry)

Thanks for your interest in contributing! 🚀
This repository is a **reference e-commerce demo** built with **Next.js** and **OneEntry Headless CMS**.

We welcome bug fixes, improvements, and enhancements that help frontend developers better understand how to use OneEntry in real projects.

---

## 🧩 What You Can Contribute

- Bug fixes
- UI/UX improvements
- Code refactoring
- Documentation improvements
- Performance optimizations
- Examples of best practices (Next.js, App Router, caching, etc.)

Check open Issues labeled:
- `good first issue`
- `help wanted`
- `documentation`

---

## 🚀 Getting Started

### 1) Fork the repository

### 2) Clone your fork

```bash
git clone https://github.com/YOUR_USERNAME/nextjs-shop-demo.git
cd nextjs-shop-demo
```

### 3) Install dependencies

```bash
npm install
```

### 4) Configure environment variables

Create a `.env.local` file and follow the instructions in `README.md`.

### 5) Run the project

```bash
npm run dev
```

---

## 🔁 Contribution Flow

1. **Create or comment on an Issue first**
2. Fork the repository
3. Create a new branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. Make your changes
5. Ensure linting passes:
   ```bash
   npm run lint
   ```
6. Open a Pull Request to `main`

---

## 📏 Code Style Guidelines

- Use existing project structure
- Follow ESLint & Prettier rules
- Prefer clear, readable code over clever solutions
- Avoid introducing breaking changes without discussion

---

## ❗ Important Notes

- This is a **demo/reference project**, not a production storefront
- Keep PRs focused and reasonably sized
- Large changes should be discussed in an Issue first

---

Thanks for contributing and helping improve the OneEntry ecosystem! ❤️
