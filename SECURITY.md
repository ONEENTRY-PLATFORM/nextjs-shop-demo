# Security Policy

## Supported Versions

This repository is a **demo / reference implementation** and is not intended for production use.
Only the latest commit on `main` is considered current.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not open a public Issue**.

Instead, report it responsibly by:

- Using [GitHub Security Advisories](https://github.com/ONEENTRY-PLATFORM/nextjs-restaurant-demo/security/advisories/new), **or**
- Contacting the maintainers directly via the OneEntry website: <https://oneentry.cloud>

Please include:

- A clear description of the issue
- Steps to reproduce (or a minimal proof-of-concept)
- The affected version / commit
- Any suggested mitigation

We appreciate responsible disclosure and will acknowledge receipt within a reasonable time frame.

---

Thank you for helping keep the OneEntry ecosystem safe.
